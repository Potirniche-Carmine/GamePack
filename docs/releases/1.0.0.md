GamePack 1.0.0 is an offline desktop app for reviewing video on macOS and Windows. Organize footage into projects, annotate a frame, and discuss it with comments and replies. Review mode pauses at commented frames.

## Downloads

- **macOS Apple silicon:** `GamePack-macos-arm64.tar.gz`
- **macOS Intel:** `GamePack-macos-x64.tar.gz`
- **Windows x64:** `GamePack-windows-x64.zip`
- **Windows ARM64:** `GamePack-windows-arm64.zip`

Extract the archive and follow its included installation instructions. macOS requires version 14 or later; Windows requires Windows 10 version 2004 or later. Node, Rust, and developer build tools are not needed to run the app.

macOS packages are ad hoc signed and not notarized. Windows packages are unsigned and require Developer Mode. SHA-256 checksums accompany every archive.

Your library stays under `~/.gamepack` (Windows: `%USERPROFILE%\.gamepack`) or `GAMEPACK_HOME`. Back up an existing library before upgrading. ZIP library exchange is not included in this version.
