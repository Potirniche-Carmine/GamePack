GamePack 1.0.4 fixes moment navigation and improves Mac installation and updates.

- Selecting a moment or one of its replies jumps to the beginning of that moment.
- Mac downloads open as a disk image. Drag GamePack into Applications to install it.
- Automatic updates work from Applications and existing GamePack data-folder installations.
- Release downloads no longer include separate checksum files. Downloads are still verified automatically.
