GamePack 1.0.1 adds in-app installation of future updates and multi-second Play annotations while keeping the review interface compact.

## Review

- Use **Moment** for a comment on one paused frame, or **Play** for one conversation across several seconds.
- Draw as the video advances, optionally at 0.5× speed. Replay reveals the drawings at their original times.
- Replies share the conversation's time range. Drafts support resume, undo/redo, and frame stepping.

## Updates

Settings can check GitHub for a newer stable release. **Update** downloads and verifies the package for your Mac or Windows device; **Restart to update** saves pending work, installs it, and reopens GamePack with the same library.

Earlier builds require one manual installation to gain this updater. A draft release is not offered in Settings.

## Downloads

- **macOS Apple silicon:** `GamePack-macos-arm64.tar.gz`
- **macOS Intel:** `GamePack-macos-x64.tar.gz`
- **Windows x64:** `GamePack-windows-x64.zip`
- **Windows ARM64:** `GamePack-windows-arm64.zip`

Extract the matching archive and follow its included installation instructions. macOS requires version 14 or later; Windows requires Windows 10 version 2004 or later. Node, Rust, and developer build tools are not needed to run the app.

macOS packages are ad hoc signed and not notarized. Windows packages are unsigned and require Developer Mode. The updater does not change those system settings. SHA-256 checksums accompany every archive.

Your library remains under `~/.gamepack` (Windows: `%USERPROFILE%\.gamepack`) or `GAMEPACK_HOME`. Back up an existing library before upgrading; older GamePack versions cannot open the newer library format.
